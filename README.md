# Spotify Mini Project 🎵

A Spotify-inspired music player UI built using HTML and CSS.

This project was created for learning and practicing frontend web development, especially layout design, Flexbox, responsive design, and CSS styling.

## 🚀 Features

- Spotify-inspired dark UI
- Sidebar navigation
- Home and Search sections
- Your Library section
- Playlist and podcast cards
- Recently Played section
- Trending music section
- Featured Charts section
- Music player bar
- Playback progress bar
- Volume control
- Responsive layout
- Font Awesome icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts
- Flexbox
